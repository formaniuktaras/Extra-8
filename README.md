# Person Extractor

Утиліта призначена для попередньої обробки архіву наказів у форматі DOCX.
Вона виконує повне сканування каталогу з наказами, знаходить усі унікальні
П.І.Б. у форматі `ПРІЗВИЩЕ Ім'я Побатькові`, формує окремі витяги за кожною
знайденою особою та надає зручний графічний інтерфейс для пошуку і відкриття
витягів.

## Можливості

- Автоматичний обхід усіх DOCX у каталозі з наказами.
- Формування індексу унікальних П.І.Б. із попередньою генерацією витягів
  (збереження «шапки», пункту, підпункту та завершальних рядків наказу).
- Збереження витягів у окремі DOCX-файли (по одному для кожної появи П.І.Б. у
  вихідному документі).
- Пошук за П.І.Б., перегляд списку джерельних документів, відкриття витягу або
  оригінального наказу безпосередньо з програми.
- Автоматичне виявлення змін у каталозі документів та перевибудова індексу.
- Вікно «Налаштування…» для вибору каталогів джерел, результатів, файлу індексу
  та теми інтерфейсу без редагування `config.json` вручну.

Окремо є вкладка «Дані», де показано дерево каталогу `source`, повний текст
обраного DOCX та поруч дубль «Вмісту витягу» з підсвічуванням абзаців, які
використані у витязі. Це дозволяє швидко звіряти витяг з оригіналом і
виконувати базові файлові операції (створення папок, перейменування, видалення).

## Структура проєкту

```
.
├── config.json                 # Конфігурація (шлях до джерел, вихідних файлів та індексу)
├── data/
│   ├── source/                 # Приклад структури з наказами (розбивка за роками/місяцями)
│   ├── output/                 # Сюди автоматично записуються витяги
│   └── index/                  # JSON-файл з попередньо обчисленим індексом
├── main.py                     # Точка входу, запускає графічний інтерфейс
└── person_extract/             # Пакет з кодом
    ├── app.py                  # Tkinter GUI
    ├── config.py               # Завантаження конфігурації та створення директорій
    ├── docx_utils.py           # Читання та створення мінімальних DOCX
    └── indexer.py              # Побудова індексу та генерація витягів
```

## Підготовка та запуск

1. Встановіть Python 3.11 (або новіший) та переконайтесь, що він доступний у PATH.
2. Скопіюйте архів наказів у каталог, вказаний у `config.json` (за замовчуванням
   `data/source`). Структура підкаталогів може бути довільною (наприклад,
   `data/source/2025/10/Наказ_292.docx`).
3. Запустіть застосунок:

   ```bash
   python main.py
   ```

   Під час першого запуску програма автоматично сформує індекс та збереже
   витяги в `data/output`.

## Оновлення після додавання нових документів

- Нові або змінені DOCX-файли просто скопіюйте до каталогу `data/source`.
- Під час наступного запуску програма автоматично виявить зміни та
  перебудує індекс. За потреби можна натиснути кнопку «Перебудувати індекс» у
  вікні програми.

## Створення виконуваного файлу (.exe)

Для постачання на Windows можна скористатися [PyInstaller](https://pyinstaller.org/):

```bash
pip install pyinstaller
pyinstaller --name person-extractor --onefile main.py
```

Отриманий виконуваний файл буде знаходитись у каталозі `dist/`. Поруч із ним
необхідно покласти каталог `data` (або змінити шлях у `config.json` на потрібний
у виробничому середовищі).

## Обмеження

- Розбір DOCX виконується на рівні XML із збереженням структурних елементів, тож
  форматування (нумерація, таблиці) у витягах відповідає оригіналу.
- Алгоритм пошуку П.І.Б. очікує формат «ПРІЗВИЩЕ Ім'я Побатькові» і може не
  розпізнати інші варіації написання.
